
## assets/ — файлы для игры

| Папка | Что внутри |
|---|---|
| `sprites/` | Герои — листы анимации `hero_*_sheet.png`: 6 кадров 12×16 (0 — стоит, 1–4 — бег, 5 — прыжок; бег 8 кадров/с по FR-SWR-2-1-1). `hero_taron_locked.png` — силуэт для закрытого героя. Враги `enemy_*.png` 12×16, боссы `boss_*.png` 20×16 (Варкс 12×16). Кристалл, сердце, флаг-чекпоинт (серый / зелёный), снаряды героя и врага. Все спрайты смотрят вправо, фон прозрачный |
| `tiles/` | Для каждой локации (desert, ice, station, junk): земля 32×120, платформа 32×24, препятствие 32×32; лазер станции 8×32 |
| `backgrounds/` | Фоны четырёх локаций 1280×720, без земли и платформ |
| `levels/` | `episode1–4.json` — 3 экрана на эпизод (2 обычных + босс, UR-3-1): платформы, препятствия, кристаллы (15 на уровень), враги, чекпоинт, место босса. Координаты в пикселях экрана 1280×720; `y` врага и босса — линия ног, `y` платформы — её верх; земля на `y = 600` |
| `data/` | `heroes.json`, `enemies.json`, `bosses.json`, `rules.json` — характеристики, скорость, прыжок, урон, очки, попадания, цены, правила кристаллов и звёзд по требованиям от 30.10 |
| `fonts/` | Press Start 2P и Rubik (woff2, кириллица + латиница), лицензия SIL OFL 1.1 |

## design/ — макеты и справка

| Файл / папка | Что внутри |
|---|---|
| `Galaxy_Runner_ekrany_itog.pdf` | Все 27 экранов с подписями «Рис. N» |
| `Galaxy_Runner_pravki_dizaina.pdf` | Какой экран какому требованию соответствует |

| `ui/tokens.json` | Цвета интерфейса, шрифты, палитра пиксель-арта |
| `ui/icons/` | Иконки интерфейса SVG: домик, замок, назад, пауза, сброс |
| `sprites_preview/` | Увеличенные спрайты и листы анимации — для просмотра |
