# Проверки Galaxy Runner по требованиям

Исполнитель: Лисин Н.Е. Проверенная версия: 0.0.0, Git 65ced41. Дата: 20.11.2026.

Папка qa содержит отдельный набор интеграционных проверок реальных Phaser-сцен, физики, данных и браузерного хранилища. В исходном коде игры исправлены модальные окна и оформление. Исходные файлы сценариев напарника не изменены. Manifest содержит тексты 40 основных требований, пути сценариев и SHA-256 документов из папки Требования.

## Запуск

1. В одном терминале: npm run qa:collect
2. Во втором терминале: npm run qa:serve
3. Открыть http://127.0.0.1:5190/qa/browser.html в имеющемся браузере. Установить размер рабочей области 1920×1080 для воспроизводимости замера. Нажать «Запустить проверки».
4. Дождаться сообщения «Проверки завершены, результаты сохранены». В конце страница автоматически перезагружается для проверки восстановления сеанса.
5. Выполнить npm run qa:report для обновления JSON и HTML-таблицы.

Результаты находятся в qa-results/report.json и qa-results/requirements.html. Снимки экранов и сырые показания — в qa-results. Excel в outputs/qa-20261120 — зафиксированный результат прогона 20.11.2026; команда qa:report обновляет HTML/JSON, а не Excel.

## Согласованные уточнения

Уточнения перечислены в acceptance.json: бонус без урона исключён, пороги 9000/10250/10250/12500; лимит кошелька 100, здоровье чекпоинта сохранённое. Дополнительные элементы UI, rex UI и время появления червя 3500 мс учтены по переписке команды и PROJECT_CONTEXT.md. Изменения критериев отражаются в отчёте и не заменяют исходные документы.

## Ограничения и база

Пройден относится к перечисленным в отчёте утверждениям, а не к полному ручному прохождению каждого Excel-сценария. Полные бои с четырьмя боссами в этом прогоне не проходились; размеры и расположение всех элементов интерфейса отдельно не измерялись. Фикстуры некоторых состояний подготовлены тестом; переходы инициируют настоящие обработчики игры. Это явно указано в отчёте.

Визуальные размеры сопоставляются с логическим масштабом 1.5 между исходным полем 1280×720 и игровым 1920×1080. Отдельная вкладка использует порт 5190, поэтому обычные сохранения игры на порту 5173 не затрагиваются. Префикс localStorage тестового адреса резервируется и восстанавливается; не прерывайте тест при выполнении перезагрузки восстановления.

По указанию пользователя не проверяются итоговый отчёт (NFR-SWR-1-1-1) и итоговая презентация (NFR-SWR-1-2-1). Используется имеющийся браузер; отдельный Google Chrome не устанавливается. GALAXY RUNNER принято как название игры, допустимое исключение из русификации.

Основные документы FR/NFR/UR выбраны как база; папки «Редактированное», «ред 9.11», «ред 11.11» содержат противоречивые варианты и автоматически базу не заменяют. Исходные Excel-сценарии напарника не редактировались.
