# Проверки Galaxy Runner

Локальный набор интеграционных проверок игры. Запускает реальные Phaser-сцены в браузере, подготавливает тестовые состояния и проверяет интерфейс, движение, боевые действия, прогресс и сохранения. ИИ и внешние сервисы не используются.

## Запуск

Из корня проекта:

1. В первом терминале — `npm run qa:collect`.
2. Во втором терминале — `npm run qa:serve`.
3. Открыть `http://127.0.0.1:5190/qa/browser.html` и нажать «Запустить проверки».
4. Дождаться сообщения «Проверки завершены, результаты сохранены». В конце прогона страница автоматически перезагрузится для проверки восстановления сеанса.
5. Выполнить `npm run qa:report`.

Во время прогона вкладка должна быть активной: фоновые вкладки могут снижать частоту кадров. Не закрывайте страницу до завершения восстановления сеанса.

## Результаты

Папка `qa-results` создаётся автоматически и не включается в Git:

- `browser.json` — результаты браузерного прогона;
- `*.png` — снимки отдельных сцен для ручного просмотра;
- `report.json` — обработанные результаты;
- `requirements.html` — отчёт для просмотра в браузере.

Команда `qa:report` обрабатывает сохранённый прогон и дополнительно проверяет текущие настройки TypeScript и зависимости. Повторный запуск этой команды не запускает игру заново. Excel-отчёты не создаются.

## Структура

| Файл | Назначение |
| --- | --- |
| `browser.html` | Страница запуска и отображения результатов. |
| `run.ts` | Сценарии проверок и восстановление тестовых сохранений. |
| `game-config.ts` | Конфигурация тестового экземпляра Phaser. |
| `acceptance.json` | Ожидаемые пороги звёзд, лимит кошелька, время появления червя и допуск отступов. |
| `manifest.json` | Идентификаторы и названия сценариев. |
| `collector.mjs` | Локальный HTTP-сборщик результатов на порту 5191. |
| `report.mjs` | Создание JSON- и HTML-отчётов. |

## Область проверки

Проверки используют программные вызовы обработчиков и подготовленные состояния: например, нужный баланс кристаллов или открытый эпизод. Полное прохождение уровней и всех последовательностей атак боссов не выполняется. Скриншоты автоматически не сравниваются. Проверки производительности относятся к текущему компьютеру и браузеру.

Сценарии сохраняют идентификаторы требований для сопоставления с документацией. Требования могут быть устаревшими; актуальное поведение определяется кодом игры. Несовпадение проверки с кодом требует проверки самого сценария, а не автоматического изменения игры.

Тестовый сайт работает на отдельном порту 5190, поэтому его браузерное хранилище отделено от игры на порту 5173. Перед прогоном ключи `galaxy-runner:` резервируются, после завершения восстанавливаются. Не используйте для проверок адрес с важным игровым сохранением.
