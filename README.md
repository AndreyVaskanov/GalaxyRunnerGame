# Galaxy Runner

Браузерный 2D-платформер в космическом сеттинге на TypeScript и Phaser.

[Играть](https://game.galaxy-runner.ru)

## Запуск

Установка зависимостей и запуск:

```bash
npm install
npm run dev
```

Если возникают проблемы с открытием, попробуйте `npm run dev -- --host`.

## Сборка и публикация

`npm run deploy` выполняет сборку и отправляет её в ветку `gh-pages`. Если ветки нет, она создаётся автоматически. Для размещения сайта в настройках GitHub Pages нужно выбрать эту ветку источником публикации.
